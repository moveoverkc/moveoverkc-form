PUT YOUR JOB PHOTOS IN THIS FOLDER.

1. Add your photo files here (JPG, PNG, or WEBP). Keep each one under about 1 MB so the page loads fast.
2. Open photos.json (in the main folder) and add one entry per photo.
   Example entry:
   {
     "file": "images/gallery/my-photo.jpg",
     "caption": "Short caption people will see",
     "alt": "Plain description of the picture for screen readers",
     "category": "Moving"
   }
3. Categories you can use: Moving, Junk Removal, Handyman, Crew
4. Commit the changes in GitHub. Your host will pick them up.

Tip: use lowercase names with dashes or underscores and no spaces (example: garage-cleanout-1.jpg).
